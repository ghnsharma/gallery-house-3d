# Gallery House · Akar Design
Luxury scroll-driven 3D walkthrough of the Gallery House, built from its floor plan. Static three.js site, no build step.

- **Story mode (default):** scroll to fly the camera along a CatmullRom spline from an aerial hero shot, through the entry court, foyer, gallery and rooms, to the infinity pool. Chapter nav on the right.
- **Explore freely:** dollhouse orbit, first-person walk (WASD/arrows, mouse look, Shift run, touch joystick), minimap teleport, auto tour.
- Desktop: bloom + 2K shadows. Mobile/touch: pixel ratio 1, no bloom, 1K shadows (`?lite` forces it, `?nobloom` disables bloom).
